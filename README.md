# نظام جدولة الامتحانات (Exam Timetabling System)

نظام ويب تفاعلي لجدولة الامتحانات باستخدام خوارزميات التحسين الميتاهيورستيكية.

## 📋 نظرة عامة

هذا المشروع يقدم واجهة ويب لجدولة امتحانات الجامعات باستخدام ثلاث خوارزميات ذكية:
- **الخوارزمية الجينية (Genetic Algorithm - GA)**
- **تحسين سرب الجسيمات (Particle Swarm Optimization - PSO)**
- **مستعمرة النمل (Ant Colony Optimization - ACO)**

يستخدم النظام أيضًا خوارزمية جشعة (Greedy Algorithm) لتوليد جدول مبدئي كنقطة بداية للتحسين.

## 🚀 طريقة التشغيل

### المتطلبات
- متصفح ويب حديث (Chrome, Firefox, Edge, Safari)
- لا يحتاج إلى خادم أو تثبيت - يعمل مباشرة من المتصفح

### الخطوات

1. **فتح المشروع**
   ```bash
   # افتح المجلد الخاص بالمشروع في المتصفح
   # أو انقر مرتين على ملف index.html
   ```

2. **تحميل البيانات**
   - انتقل إلى قسم "Data Upload"
   - اختر وضع التحميل:
     - **Bulk Mode**: رفع مجلد يحتوي على جميع الملفات
     - **Individual Mode**: رفع كل ملف على حدة
   - الملفات المطلوبة (بصيغة CSV):
     - `courses.csv` - بيانات المواد الدراسية
     - `students.csv` - بيانات الطلاب
     - `rooms.csv` - بيانات القاعات
     - `timeslots.csv` - بيانات الفترات الزمنية
     - `enrollments.csv` - تسجيلات الطلاب في المواد
     - `conflicts.csv` - تعارضات المواد

3. **تشغيل الخوارزميات**
   بعد تحميل البيانات، يمكنك تشغيل أي من الخوارزميات:
   - **Greedy**: جدول مبدئي سريع
   - **GA**: الخوارزمية الجينية (اضبط المعاملات: حجم السكان، عدد الأجيال، معدل الطفرة)
   - **PSO**: تحسين سرب الجسيمات (اضبط المعاملات: عدد الجسيمات، عدد التكرارات)
   - **ACO**: مستعمرة النمل (اضبط المعاملات: عدد النمل، عدد التكرارات، معامل التبخر)

4. **التجارب المقارنة**
   - اذهب إلى قسم "Experiments"
   - حدد عدد التكرارات (default: 10)
   - اضغط "Run Experiments" لتشغيل جميع الخوارزميات عدة مرات ومقارنة النتائج
   - شاهد الإحصائيات: المتوسط، الحد الأدنى، الحد الأقصى، الانحراف المعياري

5. **تصدير النتائج**
   - يمكنك تصدير الجداول إلى CSV من كل قسم خوارزمية
   - تصدير ملخص التجارب من قسم Experiments

## 📊 البيانات التجريبية

المشروع يأتي مع ثلاث مجموعات بيانات جاهزة للاختبار:
- **small**: مجموعة بيانات صغيرة للتجربة السريعة
- **medium**: مجموعة بيانات متوسطة
- **large**: مجموعة بيانات كبيرة للاختبار المتقدم

يمكنك استخدام هذه المجموعات أو رفع بياناتك الخاصة.

## 🎯 دالة اللياقة (Fitness Function)

تقييم الحل يتم بالمعادلة:
```
Fitness = 1000×C + 1000×R + 1000×O + 10×A
```

حيث:
- **C**: عدد التعارضات بين الامتحانات
- **R**: انتهاكات قدرة القاعات
- **O**: انتهاكات القيود الأخرى
- **A**: عدد القاعات المستخدمة (للحد الأدنى من القاعات)

الهدف هو تقليل قيمة اللياقة (Fitness) للحصول على جدول أفضل.
